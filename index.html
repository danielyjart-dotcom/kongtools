콩툴즈

콩툴즈는 문서 작업과 파일 검색에 드는 시간을 줄여 주는 Windows용 소프트웨어입니다. 콩PDF로 PDF를 정리하고, 콩Search로 필요한 파일과 문서 속 문장을 빠르게 찾을 수 있습니다. 콩see로는 그림, 도면, 3D 모델을 한 프로그램에서 열어 볼 수 있습니다.

PDF 뷰어·편집

콩PDF

PDF에서 글을 찾고, 페이지를 회전·삭제·추출하거나 여러 파일을 합칩니다.

콩PDF 내려받기 제품 소개

Windows 10 · 11 (64비트) · 설치 파일

파일명·문서 본문 검색

콩Search

파일명으로 폴더와 파일을 찾고, 한글, Word, PowerPoint, PDF 문서에서 일치 문장과 위치를 확인합니다.

콩Search 내려받기 제품 소개

Windows 10 · 11 (64비트) · ZIP

그림·도면·3D 모델 뷰어

콩see

그림, DXF와 DWG 도면, STL, OBJ, STEP, IGES 등의 3D 모델을 열어 확대하고 돌려 봅니다. 파일은 읽기만 하고 고치지 않습니다.

콩see 2.0.1 내려받기 제품 소개

버전 2.0.1 · Windows 10 · 11 (64비트) · 설치 파일

콩PDF 제품 소개

무엇을 할 수 있나요

자주 하는 일을 한 화면에서 합니다.

보기

연속 스크롤, 너비·쪽 맞춤, 확대와 축소. 쪽 미리보기와 책갈피로 원하는 곳에 바로 갑니다.

찾기와 복사

문서 전체에서 글을 찾아 결과를 차례로 봅니다. 본문의 글을 끌어서 골라 복사합니다.

탭

여러 PDF를 탭으로 열어 둡니다. 탭마다 보던 쪽과 배율을 기억합니다.

쪽 정리

쪽을 바둑판으로 늘어놓고 돌리기, 지우기, 끌어서 순서 바꾸기. 실행 취소가 됩니다.

나누기와 추출

고른 쪽만 새 파일로 추출하거나, 문서를 쪽 수나 범위로 나누어 저장합니다.

합치기

PDF 여러 개를 골라 순서와 넣을 쪽을 정하고 새 파일 하나로 합칩니다. 원본은 바뀌지 않습니다.

인쇄

프린터와 쪽 범위를 골라 종이에 맞춰 인쇄합니다.

어두운 화면 · 밝은 화면

버튼 하나로 화면 색을 바꿉니다.

전체 화면 발표

F11을 누르면 쪽 하나가 화면을 가득 채웁니다. 휠이나 화살표 키로 한 쪽씩 넘기고, 오른쪽의 가는 막대로 지금 위치를 봅니다. F11이나 Esc로 돌아옵니다.

여러 언어

한국어, English, 中文, 日本語, Русский, العربية로 쓸 수 있습니다. 아랍어에서는 화면이 오른쪽에서 왼쪽으로 놓입니다.

업데이트

새 버전이 나오면 알려 주고, 누르면 받아서 설치합니다. 받은 파일이 올바른지 확인한 뒤에만 설치합니다.

쪽을 한눈에 보며 정리

"구성 편집"을 누르면 쪽이 바둑판으로 펼쳐집니다.

  1. 쪽을 눌러 고릅니다. Ctrl이나 Shift로 여러 쪽을 고릅니다.
  2. 돌리거나 지우거나, 끌어서 순서를 바꿉니다.
  3. 고른 쪽만 새 파일로 추출하거나 다른 PDF를 끼워 넣습니다.
  4. "저장"을 누르기 전에는 원래 파일이 바뀌지 않습니다.

설치할 때 Windows가 경고할 수 있습니다. 설치 파일에 코드 서명이 없어서 "Windows의 PC 보호" 창이 뜰 수 있습니다. 내려받은 파일의 SHA-256이 왼쪽 값과 같은지 확인한 뒤, "추가 정보" → "실행"을 눌러 설치합니다.

  1. 관리자 권한 없이 내 계정에만 설치됩니다.
  2. PDF의 기본 프로그램을 바꾸지 않습니다. 다른 PDF 프로그램은 그대로입니다.
  3. 제거해도 내 PDF와 문서는 지워지지 않습니다.
  4. 프로그램이 인터넷에 보내는 것은 새 버전이 있는지 묻는 요청뿐입니다.

콩Search 제품 소개

파일명이 기억나면 이름으로, 문서 속 문구만 기억나면 내용으로 찾으세요.

입력하는 즉시 파일 찾기

검색어를 입력하면 파일과 폴더가 바로 나타납니다. 폴더·확장자·수정일로 좁히고, 결과를 스크롤로 이어서 봅니다.

문서를 열기 전에 일치 위치 확인

HWP·HWPX·DOCX·PPTX·텍스트 PDF에서 일치한 문장의 일부를 보여줍니다. PDF는 페이지, PPTX는 슬라이드 번호까지 표시합니다.

색인 중에도 검색 계속하기

파일 목록은 백그라운드에서 갱신하고, 준비된 항목부터 검색합니다. 내용 검색은 OneDrive 등의 온라인 전용 파일을 건너뜁니다.

콩Search 내려받기

Windows 10 · 11 (64비트) · 0.5.14 · ZIP을 풀고 KongSearch.exe를 실행하세요.

콩see 제품 소개

그림, 도면, 3D 모델을 프로그램 하나로 열어 봅니다.

그림

JPEG, PNG, GIF, BMP, TIFF, WebP 파일을 엽니다. 같은 폴더의 다음 파일과 이전 파일로 넘어갑니다.

도면

DXF와 DWG 도면을 엽니다. 선, 원호, 스플라인, 해치, 글자, 치수를 그리고, 확대해도 선이 깨지지 않습니다.

3D 모델

STL, OBJ와 STEP, IGES, BREP, glTF, VRML 파일을 엽니다. 끌어서 돌리고, 표준 시점과 방향 상자로 보는 방향을 바꿉니다.

보기

어두운 화면과 밝은 화면, 전체 보기 (F11), 인쇄 (Ctrl+P)를 지원합니다.

여러 언어

한국어, English, 日本語, 中文, Русский, العربية로 쓸 수 있습니다.

업데이트

새 버전이 나오면 알려 주고, 받은 파일의 SHA-256을 확인한 뒤에만 설치합니다.
